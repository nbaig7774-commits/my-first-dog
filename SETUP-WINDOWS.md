# My First Dog — run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Copy `.env.local.example` to `.env.local`.
4. Put your Supabase API URL and Publishable key in `.env.local`.
5. In VS Code Terminal run `npm install`.
6. Run `npm run dev`.
7. Open `http://localhost:3000`.
8. In Supabase SQL Editor run `supabase/schema.sql`.
9. Open `/login`, create a test account, then add a dog.
Never put a secret/service-role key in `.env.local` for the browser.
